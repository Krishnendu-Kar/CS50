# CS50x — Introduction to Computer Science

My work through Harvard's CS50x (2026), taken as the foundation of a longer path toward systems and low-level engineering.

Started **September 2026** · Target completion **March 2027**

---

## Why

I'm a first-year IT student. CS50 is where I learn C properly — pointers, memory, and what actually happens underneath the languages I'd otherwise take for granted. The goal isn't the certificate. It's being able to reason about a program all the way down.
